# Origin of This Experiment

Created as a separate repository on **10 October 2026** for the proposed brief-touch mechanics study.

The experiment design and literature review were first written in [tactile-contact-research](https://github.com/EltonChang1/tactile-contact-research/blob/c6fee1245a86bd45c3a6bcbe16c838e1b4a4c5d9/README.md), at commit [`c6fee12`](https://github.com/EltonChang1/tactile-contact-research/commit/c6fee1245a86bd45c3a6bcbe16c838e1b4a4c5d9). This repository now maintains the mechanical experiment. The earlier repository contains the vibration-prediction implementation and its development results.

Original experiment code, raw data, trained models and validation results were not copied. The earlier study's passing tests and reproduced results belong to that study. Force calibration, mechanical collection, prediction methods and motion validation here remain future work.

Start with the [README](../README.md) and [methods](methods.md). The first milestone is confirming suitable force, motion and tactile measurements.
